# Kaggle & Data Analysis Portfolio 📊
## English
Welcome to my portfolio repository! Here I collect my practical projects on data analysis, solving Kaggle problems, and developing interactive dashboards.

Each folder in this repository is dedicated to a separate dataset and contains two files:
1. **Jupyter Notebook (.ipynb)** — a full data workflow: from cleaning and preprocessing to exploratory data analysis (EDA) and visualization.
2. **Dashboard/Report** — an interactive visualization of metrics or a final presentation of project findings.

 ---

### 🛠 Tech Stack

In my projects, I use Junior Data Analyst tools:

* **Programming Languages:** Python
* **Analysis Libraries:** Pandas, NumPy
* **Visualization:** Matplotlib, Power BI (Power Query, DAX)
* **Databases:** PostgreSQL (SQL)

---

### 📈 Project Methodology

The approach to each dataset is built according to industry standards and includes the following stages:

1. **Data Gathering & Understanding:** Loading data, examining the structure and data types, finding gaps and duplicates.
2. **Preprocessing and Cleaning:** Handling missing values, filtering out anomalies, converting to the required types, optimizing memory consumption.
 3. Exploratory Data Analysis (EDA): Developing and testing hypotheses, finding hidden patterns, performing correlation analysis, and calculating statistical metrics.
4. Visualizing and Presenting Insights: Creating visual graphs in Python and building interactive dashboards for key stakeholders to quickly interpret metrics.

### 📈 Методология работы над проектами

Подход к каждому датасету выстраивается по стандартам индустрии и включает в себя следующие этапы:

1. **Сбор и первичное знакомство (Data Gathering & Understanding):** Загрузка данных, изучение структуры, типов данных, поиск пропусков и дубликатов.
2. **Предобработка и очистка (Data Cleaning):** Работа с пропущенными значениями, фильтрация аномалий, приведение к нужным типам, оптимизация потребления памяти.
3. **Исследовательский анализ (EDA):** Выдвижение и проверка гипотез, поиск скрытых закономерностей, корреляционный анализ, расчет статистических метрик.
4. **Визуализация и презентация инсайтов:** Построение наглядных графиков в Python и сборка интерактивных дашбордов для быстрой интерпретации показателей ключевыми лицами.
